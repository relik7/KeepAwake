# Keep Awake
 - Prevents automatic sleep in Windows 8, 10, and 11.  This includes Modern / Connected Standby.
 - System tray icon with toggle on/off.  Right click the icon in system tray to exit.
 - Designed to be widely compatible with 32-bit and 64-bit systems
 - Only requires .NET Framework 4.0 runtime, pre-installed on every Windows 8+ PC already.

You can build this same EXE using the source files on any Windows 8 or newer PC without any software.
 - Clone the repo or uncompress the latest source release
 - Run `build.bat`

A compiled EXE is provided under releases for ease of use.
